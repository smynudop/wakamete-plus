プレイヤー・ルームに要素追加

## プレイヤー
* handleName
  * プレイヤー名とは別に個人を識別する名前
  * 入室時に設定する
  * ゲーム終了まで全体には公開しない
* color
  * 表示の彩りに使用する
  * 10色ぐらいプリセットで用意する
  * ユーザーが入室するときに選べる
* password
  * 離脱時の復帰用に、入室時に指定して保持しておく。実際の活用は後回しでよい。

## ルーム
以下の情報はルーム単位に持たせる。

* roomName
  * ルームの名称。
* pr
  * ルームの宣伝文。
* durationSeconds
  * 各フェーズの秒数。30～300秒の間で設定できるようにする
* playerLimit
  * 参加人数の上限。npcを含めて4～20人まで設定できるようにする。

現在はルーム1つなので、適当なものを固定で設定しておく。ただルームに持たせるようにする。

# v1 実装メモ

2026-07-23 時点のプロトタイプ実装内容を記録する。

## 実装したもの

- `pnpm` workspace による TypeScript モノレポ構成を追加した。
  - `shared`: サーバーとフロントエンドで共有する型定義
  - `server`: Express + Socket.IO によるゲームサーバー
  - `frontend`: Vite + Vue による最小プレイ UI
- 固定1ルーム、NPC込み6人村を実装した。
  - 人間プレイヤー5人
  - NPC「初日犠牲者」1人
  - 役職は人狼1、狂人1、占い師1、村人3
- サーバー側に `GameRoom` を実装し、ゲーム状態管理を Socket.IO ハンドラから分離した。
- 以下のフェーズ進行を実装した。
  - 1日目: 夜の議論、夜の襲撃
  - 2日目以降: 昼の議論、昼の投票、夜の議論、夜の襲撃
- 各フェーズのサーバータイマーを実装した。
  - 昼の議論: 180秒
  - 昼の投票: 60秒
  - 夜の議論: 90秒
  - 夜の襲撃: 60秒
- 投票、占い、襲撃、チャットの基本操作を実装した。
- 勝敗判定を実装した。
  - 人狼全滅で村人陣営勝利
  - 生存人狼数が生存人間数以上で人狼陣営勝利
  - 狂人は勝利陣営としては人狼陣営、人数カウント上は人間
- ゲーム終了時に勝敗、全員の役職、簡易ログを公開するようにした。
- ブラウザ保存のセッショントークンによる自動復帰を実装した。
  - 切断やページ再読み込み後も同じプレイヤー、役職、個人状態へ復帰する。
  - トークンを失った場合はプレイヤー名と復帰用パスワードで手動復帰できる。

## 主なファイル

- `shared/src/index.ts`
  - 役職、フェーズ、公開ゲーム状態、個人状態、Socket.IO イベント型を定義。
- `server/src/game.ts`
  - ゲームルール、状態遷移、投票、占い、襲撃、勝敗判定を実装。
- `server/src/index.ts`
  - Express の静的配信と Socket.IO イベント処理を実装。
- `frontend/src/App.vue`
  - 参加、開始、状態表示、チャット、投票、占い、襲撃、終了表示の最小 UI を実装。
- `server/tests/game.test.ts`
  - ゲームロジックの単体テストを追加。

## 起動方法

依存関係を入れていない場合は、リポジトリルートで次を実行する。

```bash
pnpm install
```

開発サーバーを起動する。

```bash
pnpm dev
```

既定では `http://localhost:3000` で Express + Socket.IO サーバーが起動する。

## 検証方法

単体テストを実行する。

```bash
pnpm test
```

全 workspace をビルドする。

```bash
pnpm build
```

実装時点では、以下を確認済み。

- `pnpm test`: 7 tests passed
- `pnpm build`: shared / server / frontend build passed

## v1 の制限

- ルームは1つだけ。
- 観戦者、死亡者チャット、認証、永続DBは未実装。
- ゲームログはメモリ上で簡易的に保持し、ゲーム終了時にクライアントへ返すのみ。
- UI はプロトタイプとして、ゲーム進行確認を優先している。
